# L14 — Lỗi tạo hình (tay, mặt méo, chữ lạ)
Áp dụng: ảnh, video
Nghề gốc: lỗi ảnh / video AI (`knowledge/ai_image_failure_modes.md`)

## Câu hỏi khai được
- Với từng nhóm — tay / ngón, mặt méo, chữ lạ / logo giả, vật dính người — "có thấy không?" → `co` / `khong`, kèm chỗ (người / vật
  nào). Chưa có (đợt K3).

## Code kết luận thế nào
| Khai | So với | Kết luận |
|---|---|---|
| `co` ở nhân vật chính (BYĐ `vai: chinh`) hoặc mặt | — | ĐỎ |
| `co` ở nền xa / vai phụ nhỏ | — | VÀNG |
| chữ lạ `co`, BYĐ có HUD / UI / chữ cố ý (T1) | `ngoai_le` | qua nếu đúng chỗ tả |
| `khong` | — | qua |
| thiếu / ngoài enum | — | VÀNG |

## Đo bằng code hiện có
- KHÔNG có cách đo bằng code (bảng ghi `code_do` rỗng); lớp Claude cũng chưa có (đợt K3) → L14 hiện không có cách kiểm nào chạy.

## Gợi ý nhìn kỹ (lẽ thường, không phải luật)
- Thừa / thiếu ngón, tay dính vật; mắt lệch; vũ khí hợp nhất vào người / nền; ký tự vô nghĩa trên biển hiệu.
- Video: `face_morph`, `body_deform`, `text_logo_corrupt` (`knowledge/i2v_motion_discipline.md`).
- Khung trống / đen / một màu là lỗi kỹ thuật lớp 0 (qc_playbook D1), không thuộc câu khai này.
