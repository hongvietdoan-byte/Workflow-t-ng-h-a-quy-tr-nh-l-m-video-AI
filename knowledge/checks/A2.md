## Code kết luận thế nào
| Nguồn | So với | Kết luận |
|---|---|---|
| loudness (LUFS, LRA, true peak) | mức xuất bản + nhạc dưới thoại | vượt mức / nhạc lấn thoại → ĐỎ; không đo được (không tiếng / không ffmpeg, hàm trả None) → VÀNG |
| mốc nhịp (đổi nhạc, điểm đập) | BYĐ nhịp + đường cảm xúc cả truyện | lệch → ĐỎ — CHƯA có code (đợt K6) |
| Claude SFX `khong` | BYĐ `am_chu` / hành động T1 | ĐỎ |
| Claude SFX `co` | — | qua |
- Khoảng lặng có chủ đích (BYĐ, T1) không phải lỗi thiếu tiếng.

## Đo bằng code hiện có

- Mốc nhịp so BYĐ: chưa có (đợt K6).
