# A1 — Thoại: đúng câu, đúng người, đúng giọng
Áp dụng: âm-chữ
Nghề gốc: âm thanh-dựng (thoại / TTS) + giám sát kịch bản (`knowledge/dialogue_craft.md`)

## Câu hỏi khai được
- Không có câu khai cho lớp Claude (bảng ghi `claude_khai` rỗng) — đúng câu, độ dài đo bằng code; đúng người / đúng giọng là so dữ liệu.

## Code kết luận thế nào
| Số đo / dữ liệu | So với | Kết luận |
|---|---|---|
| `check_line` → `problems` (giọng quá ngắn = bị cắt, quá dài = lặp, im lặng giữa câu, cụt đuôi) | câu thoại BYĐ | có → ĐỎ (giữ bản cũ, làm lại theo yêu cầu) |
| chữ nghe được (faster-whisper) so từng chữ | câu thoại BYĐ | thiếu / sai chữ → ĐỎ |
| không có faster-whisper (`asr: false`) | — | phần so chữ VÀNG — chỉ đo độ dài + im lặng |
| người nói của dòng thoại | BYĐ `am_chu` (ai nói) | khác → ĐỎ — CHƯA có code (④ âm/chữ, đợt K6) |
| giọng dùng | hồ sơ giọng nhân vật (`data/voices_vi.json`) | khác → ĐỎ — CHƯA có code (K6) |
| độ dài giọng > độ dài shot | BYĐ / thời lượng shot | ĐỎ — CHƯA có code (K6) |

## Đo bằng code hiện có
- `core/voice_check.py:check_line` — kiểm TTS: cắt, im lặng, độ dài, so chữ (so chữ cần faster-whisper); bảng không gắn cờ.
  Tự làm lại giọng khi lỗi còn dưới cờ `voice_check_redo` (chưa verified) — không thuộc phép kiểm.

## Gợi ý nhìn kỹ (lẽ thường, không phải luật)
- Đổi một chữ là giọng / khớp môi lệch; tiếng Việt thoải mái ~3,5 âm tiết/giây; lời thoại sạch (không mày/tao, nói tục).

## Ca lỗi thật
- Thoại sai người nói — kế hoạch K0b yêu cầu làm ca hồi quy âm/chữ; CHƯA có tệp trong `tests/golden/cases/` (việc mở).
