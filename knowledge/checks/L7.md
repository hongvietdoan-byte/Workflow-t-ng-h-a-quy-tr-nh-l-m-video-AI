# L7 — Vật: có / không, phần thấy, hình dáng
Áp dụng: ảnh, video
Nghề gốc: VFX ghép hình (phối cảnh) + thiết kế bối cảnh

## Câu hỏi khai được
Câu observe của `core/stage_facts.py` — enum `theo FACTS[kind].observe.options`, luôn có `unsure`:
- `top_visible`: "Thấy VÀO trong vật (miệng / lòng) hay chỉ thành ngoài?" → inside_visible / only_outer_wall / not_in_frame / unsure.
- `stand_in`: "Vật vẽ thành vật thật (đá, vân) hay khối phẳng trơn?" → drawn_as_real_object / flat_plain_block / not_in_frame / unsure.
- `ref_viewpoint`: "Vật nhìn từ trên cao (như ảnh sản phẩm) hay từ máy của khung?" → copied_reference_angle / frame_camera_angle /
  not_in_frame / unsure.
Học việc (đợt K3), kết luận ở `core/stage_facts.py:judge`, cờ `scene_qc`.

## Code kết luận thế nào
So với SỰ THẬT HÌNH HỌC (`core/stage_facts.py:derive` từ máy 3D + đạo cụ: cao máy vs miệng vật, khối thay thế, trong khung):
| Sự thật | Khai | Kết luận |
|---|---|---|
| top_visible = False (máy thấp hơn miệng) | inside_visible | ĐỎ |
| top_visible = False | only_outer_wall | qua |
| stand_in = True | flat_plain_block | ĐỎ |
| ref_viewpoint = differs | copied_reference_angle | VÀNG (ĐỎ do top_visible quyết, không đếm hai lần) |
| vật chắc trong khung | not_in_frame | ĐỎ / VÀNG theo % trong khung |
| bất kỳ | unsure / thiếu / ngoài enum | VÀNG |
- TRƯỚC gen: `contradicts` (regex) bắt câu prompt trái hình học ("into the well", "dark mouth", "mouth facing us") → ĐỎ trả Đạo diễn.

## Đo bằng code hiện có
- `core/stage_facts.py:derive` — sự thật hình học; cần máy 3D đã giải, cờ `stage_camera` mặc định TẮT → KHÔNG tính khi cờ tắt.
- Lớp khai `judge` dưới cờ `scene_qc` (TẮT) → KHÔNG tính.

## Gợi ý nhìn kỹ (lẽ thường, không phải luật)
- Bóng tiếp xúc, phối cảnh khớp đường chân trời, vật thật có vân / khe / rêu. Render 3D xám = khối thay thế, không phải hình cần chép.
