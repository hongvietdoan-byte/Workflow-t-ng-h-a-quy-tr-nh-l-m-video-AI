# L12 — Thời gian, thời tiết, ánh sáng
Áp dụng: ảnh, video
Nghề gốc: thiết kế bối cảnh / ánh sáng (giờ, thời tiết, nguồn sáng)

## Câu hỏi khai được
- "Thời gian nào?" → `ngay` / `dem` / `binh_minh` / `hoang_hon` / `unsure`. "Có sương không?" → `suong` / `khong_suong` / `unsure`. Chưa có (đợt K3).
- Nguồn sáng (trăng / đèn ở phía nào): CHƯA có enum — vị trí là việc của code (N5).

## Code kết luận thế nào
| Khai | So với | Kết luận |
|---|---|---|
| `ngay` / `dem` / `binh_minh` / `hoang_hon` | BYĐ T1 `noi_chon` thời gian (`plate_env.TIMES`: dawn / day / dusk / night) | day↔ngay, night↔dem, dawn↔binh_minh, dusk↔hoang_hon trùng → qua; ngược → ĐỎ |
| thiếu / không chắc thời gian | BYĐ dawn / dusk | không kết luận, VÀNG |
| `suong` / `khong_suong` | BYĐ thời tiết (`plate_env.WEATHERS`) | trái → ĐỎ |
| `unsure` / thiếu | — | VÀNG |
| màu trời đo được | thời gian BYĐ | lệch rõ → VÀNG (số đo thắng khi có trời trong khung) |
- Nguồn sáng: hướng trăng phải suy từ máy 3D + hướng trăng của cảnh (sự thật hình học) — CHƯA có trong `stage_facts` → hiện không kiểm.
