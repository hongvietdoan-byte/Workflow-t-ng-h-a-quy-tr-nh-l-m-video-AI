## Chạy thử fixture giả, 0 USD

Chạy PowerShell từ worktree. Đoạn này **chỉ tạo fixture tổng hợp trong thư mục tạm**, không trích dự án thật; nhãn `fixture-human` là giả, không dùng kết luận chất lượng.

```powershell
$benchRoot = Join-Path ([IO.Path]::GetTempPath()) ('qc-bench-demo-' + [guid]::NewGuid())
New-Item -ItemType Directory -Path $benchRoot | Out-Null
$raw = [Text.Encoding]::UTF8.GetBytes('{"prompt":"Có chữ Việt","text_stage":"final_sent_text"}')
[IO.File]::WriteAllBytes((Join-Path $benchRoot 'package.json'), $raw)
$sha = [Convert]::ToHexString([Security.Cryptography.SHA256]::HashData($raw)).ToLowerInvariant()
$case = @{
  case_id='demo-1'; qc_code='QC-PKG-VI_TEXT'; qc_path='Q9'; artifact_kind='package'
  artifact='package.json'; artifact_sha=$sha; project_id=24; scene_idx=1; job_id=$null
  source_ref='synthetic:demo'; label='LOI'; label_by='fixture-human'
  label_at='2026-10-21T04:00:00+07:00'; label_note='fixture giả'; label_confirmed=$true
  split='independent'; synthetic=$true
  capture=@{commit_sha=('a'*40); flags_snapshot=@{shadow=$false}; schema_version=1
            provider=$null; model=$null; prompt_sha=$null}
}
ConvertTo-Json -InputObject @($case) -Depth 8 | Set-Content (Join-Path $benchRoot 'cases.json') -Encoding utf8NoBOM
py tools/qc_benchmark.py (Join-Path $benchRoot 'cases.json') --artifact-root $benchRoot --format markdown
py tools/qc_benchmark.py (Join-Path $benchRoot 'cases.json') --artifact-root $benchRoot --format json
```

CLI xuất stdout, mã thoát 0 nếu mọi ca đủ hỗ trợ (kể cả checker kết luận lỗi), 1 khi có UNSUPPORTED/INSUFFICIENT_INPUT/CHECKER_FAILED, 2 khi bộ ca sai. Mã 0 **không chứng nhận QC đạt**. Caller cần lưu JSON/Markdown ở vị trí báo cáo riêng nếu muốn; công cụ không persist calibration.

`related_areas.py` đã chạy cho 6 file code/test: nhận step2, không caller hiện có; các vùng dùng chung cờ chỉ là quan hệ trong bản đồ (không thêm/sửa cờ nào). Không đụng test slow theo công cụ; cả bộ vẫn để phiên tích hợp chạy.
