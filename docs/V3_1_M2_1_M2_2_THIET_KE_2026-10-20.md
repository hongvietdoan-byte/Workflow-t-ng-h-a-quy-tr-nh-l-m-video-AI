## 2. Schema BYĐ v2 (đề xuất)
```jsonc
"byd": {
  "byd_v": 2,                                  // thiếu = v1
  "shot": 7, "truyen": {...}, "thanh_phan": [{"vat": "KELLY", "kho_id": 12, "vai": "chinh", "thay": "mat", "dang": "ghost_form"}],
  "hanh_dong": [...],                          // như v1
  "vat": [{"vat": "BOM_KEO", "kho_id": 367, "nguoi": "KELLY", "cach": "nem", "bien_the": "curved_deployed"}],
  "may": {...}, "noi_chon": {"kho_id": 41, "spot": "...", "trong_nha": null, "thoi_gian": "dusk", "thoi_tiet": "fog", "anh_sang": null},
  "khung": {"moc_nen": {"kho_id": 88, "y_do": "trong_khung", "ly_do": ""}},     // nhóm MỚI — thêm vào GROUPS (v1 sẽ báo "trường lạ")
  "ngoai_le": [...], "am_chu": {...},
  "_p": {"by": "director|human|backfill|code", "model": "...", "at": "...", "revision": 3}   // provenance cấp BYĐ (M0.10 Actor)
}
```
- `vat[]`: `vat` (tên, giữ khóa cũ để `qc_observe` không vỡ), `kho_id` (bắt buộc v2), `nguoi` ∈ `thanh_phan[].vat`, `cach` ∈ {cam, deo, dat, nem}, `bien_the`
  ∈ `forms[].ma` của mục Kho (M0.9: snake_case tiếng Anh, vd `curved_deployed` — G38) — chưa có `forms` → WARN `bien_the_khong_kiem_duoc`.
- `thanh_phan[].dang`: giữ 3 dạng hiện có (chữ / danh sách / `{nhip: …}`); v2 + Kho có `forms` → phải ∈ `forms[].ma` (A2a).
- `noi_chon.trong_nha`: **code suy** từ chỗ đứng 3D (`runner.indoor_spot`); Đạo diễn chỉ khai khi không có chỗ đứng 3D.
- Giờ / thời tiết: giữ quyết định một nguồn (shot `time`/`weather`); `noi_chon.thoi_gian/thoi_tiet` là bản chép (trigger) — v2 KHÔNG thêm nguồn mới.
- `shot` thiếu → tự điền số thứ tự + diag (sổ `byd-auto-shot-number-2026-10-15`), ghi qua guard M2.5.

### 2.1 Mức BLOCK / REVIEW / WARN (thay "do"/"vang")
| Mức | Khi nào | Hệ quả |
|---|---|---|
| BLOCK | sai schema v2 (kiểu, enum), `kho_id` không có trong `assets`, `vat.nguoi` không thuộc `thanh_phan`, nhóm bắt buộc thiếu | Đạo diễn sửa ≤ 2 vòng (`director_byd.settle`); còn BLOCK → shot không gen (cổng như `video_pregen` ĐỎ) |
| REVIEW | lệch ý đồ ↔ số đo (`khung.moc_nen.y_do` vs `plate_anchor.landmark_facts`), `dang`/`bien_the` ngoài `forms`, BYĐ DRAFT của shot chèn (M2.4) | REVIEW_REQUIRED (M0.10) — người duyệt; không chặn job khác |
| WARN | `text_vs_field` (chữ prompt nói X, trường nói Y), fallback v1 / đọc chữ, thiếu trường tùy chọn | diag `byd_fallback` / `text_vs_field`, không đổi gói |
Ánh xạ tương thích: "do" cũ = BLOCK; "vang" cũ = WARN (test giữ khớp). v1 không bao giờ BLOCK vì thiếu trường v2.

### 2.2 Hàm đọc chung
`shot_intent.read(data, field) -> (value, provenance, warn)`; `provenance` ∈ `byd_v2` / `byd_v1` / `suy_tu_spot` / `doc_chu` / `thieu`.
v2 đủ trường → `byd_v2`; v1 → đọc như hôm nay (`vat_items`, …) + `byd_v1`; thiếu → đường cũ (đọc chữ) + `doc_chu` + diag `byd_fallback` (luật 1).
Mọi caller ở bảng 1.1 đổi sang `read()` — test AST: ngoài `shot_intent.py`, không file `core/` nào truy cập `data["byd"][…]` trực tiếp (danh sách ngoại lệ có lý do).
