## Tìm ra: API có cả hai model (không có trong skill công khai 1.3.1)
Đọc mã web ClipAI (JS công khai, 0 USD) — trang Audio Generation:
- **Eleven Music v2.5** = `model: "music_v2_5"` (cùng `provider: elevenlabs`, `type: music`, `input_params` như `music_v2`). API nhận và trả
  bài thật (asset 30779) → **API CÓ model này**.
- **Seed Audio 1.0** = `POST /api/sound/generate` với `{"provider":"seedance","type":"tts","model":"seed-audio-1.0","text":…,"name":…,
  "output_format":"mp3","sample_rate":44100,"speech_rate":0,"loudness_rate":0,"pitch_rate":0,"enable_subtitle":true,"aigc_watermark":false,
  "references":[{"audio_url":…}×≤3 | {"image_url":…}]}` — các tham số ở **cấp ngoài** (không trong `input_params`); chữ ≤ 3000 ký tự;
  ảnh HOẶC ≤ 3 âm (mỗi âm ≤ 30 s, 10 MB); gọi giọng bằng `@Audio1..3`; mốc `[1.0s:2.5s]` trước câu. API **nhận** yêu cầu (trả asset id,
  lưu `provider: seedance`) nhưng nhà cung cấp trả **400** ngay.
- Hướng dẫn Seed Audio chính thức (nhúng trong web): mẫu tần số liệt kê **48K/40K/24K/16K/8K** (không có 44,1K — nhưng web mặc định
  gửi "44100"); "Use only authorized voice materials"; bật mốc phụ đề để dựng chính xác.
