C. YÊU CẦU ĐỀ NGHỊ DUYỆT
Thông tin/quyền cần được cấp
Hạng mụcNội dung cần
Xác thựcAPI key / token (lưu bằng biến môi trường trên máy vận hành, không đưa vào repo)
EndpointTạo task image-to-video · lấy trạng thái · (webhook nếu có) · tải video · hủy task
Đầu vào mỗi task1 ảnh (png/jpg) + motion prompt + negative prompt + thời lượng (mặc định 5s)
Giới hạnRate limit, số task chạy song song, thời gian xử lý trung bình/timeout, dung lượng file
LỗiTài liệu mã lỗi, đặc biệt "Failure to pass the risk control system"
Hạn mức & chi phíQuota/credit cho giai đoạn thử nghiệm và khi mở rộng batch >100 clip
Quy mô sử dụng đề xuất
  • Giai đoạn thử nghiệm (V0): ~2 kịch bản, 10–20 clip → tối đa ~60 request nếu mọi cảnh phải retry 3 lần
  • Giai đoạn vận hành: batch có thể >100 clip → cần polling dài, không thể duyệt tay từng request
  • Hạn mức cụ thể: ........ request/ngày (điền sau khi thống nhất)
Bảo mật & dữ liệu
  • Chỉ gửi ảnh cảnh do pipeline tạo + prompt văn bản; không gửi dữ liệu cá nhân
  • API key chỉ nằm trên máy vận hành; repo mã nguồn không chứa key
  • Mọi lần gọi được ghi log (job, trạng thái, lỗi) để kiểm toán và tính chi phí
