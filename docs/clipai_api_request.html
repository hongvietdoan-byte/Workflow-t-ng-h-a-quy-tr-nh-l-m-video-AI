B. CLIP AI API INTEGRATION DETAILS
Dashboard (Streamlit)Controls: Start batch · Pause/Resume polling · Retry failed jobs · Cancel job.
Shows progress x/y + risk-control warnings
mcp-server-clipai
  • Submit: image + prompt + duration
  • Heartbeat polling (default 90s)
  • Download .mp4 to /videos/
  • State machine: queued→running→succeeded/failed
  • Max 3 retries, then escalate to a person
Clip AI / Kling API (access requested)
  • Create image-to-video task
  • Query task status (or webhook)
  • Download result · cancel task
  • Clear error codes/messages (incl. risk control)
Cost & risk controls
  • Only approved images are sent
  • Pre-flight IP check: flags characters matching IPs blocked by Kling (e.g. Wonder Woman) before any API call
  • Retries capped at 3 → prevents wasting credits
  • Emergency Pause / Cancel-all buttons
