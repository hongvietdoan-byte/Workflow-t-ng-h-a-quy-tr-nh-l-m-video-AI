Mỗi đợt: `pregen_check --project N` → người dùng đồng ý số tiền → gửi.

**Tiêu chí đạt (tất cả):**
1. 0 job trả tiền trùng / gửi lại khi trạng thái không rõ (`send_claim`, `jobs`).
2. Gen lại tự động ≤ trần (ảnh ≤ 3, video ≤ 2; nháp 2 / bản cao 1 khi 2 bậc) và **mỗi lần đổi đầu vào** (`jobs.input_hash` khác) — 0 vi phạm.
3. Chi phí thật ≤ dự toán đã duyệt × 1,10 (lệch ≤ 10 % — nghiệm thu M1.6); không vượt thì ghi lệch thật.
4. Tỉ lệ duyệt video lần đầu **≥ 40 %** (ĐÃ CHỐT 20/10 — vòng đo mốc; #24 Seedance 2.0 ≈ 6 % là lý do bỏ 2.0).
5. Continuity: 0 lỗi mã G1/G41–G45/G27/G37 trên các shot thử (đúng lỗi vòng A đã sửa không tái diễn).
6. Can thiệp tay **≤ 2 lần / shot** (ĐÃ CHỐT 20/10; sửa trường + override + gen lại tay), khóa tay không bị AI ghi đè (M2.5: 0 `field_conflict` bị ghi đè).
7. QC: 0 crash; báo nhầm ≤ ngưỡng benchmark (M4.6) — QC ở shadow/REVIEW, không tự BLOCK (D07).
8. Final QC (blackdetect/freezedetect — M4.4) qua; bản giao ≥ 720p gốc (cấm 480p phóng — `final_cut.require_delivery_resolution`).

**Điểm dừng (dừng đợt, báo người dùng):** cùng lỗi 2 lần ở một shot (luật 6); chi thật > 120 % dự toán đợt; bất kỳ job trả tiền trùng; nhà
cung cấp báo hết tiền (`out_of_credit`) / hết lượt Claude (`usage_limit`) — dừng, không tự đổi sang API trả phí (D02); QC crash; khóa tay bị ghi đè.

## Phụ lục A — script dự toán (chạy lại được, 0 USD, chỉ import hàm giá)

```python
import sys; sys.path.insert(0, "<repo>")
from core import cost
from core.pipeline import AUTO_REGEN_LIMIT
from core.quality_tier import RETRY_LIMIT
P = cost.load_pricing(); M25 = "dreamina-seedance-2-5-260628"
img = P["per_image"]["dola-seedream-5-0-pro-260628"]
sd = lambda res, s, vin=0.0: cost.seedance_estimate(M25, res, "9:16", s, vin)
llm = {st: cost.llm_call_usd(None, st, P, images=(1 if st in ("qc", "director_rewrite") else 0))
       for st in ("director", "director_byd", "motion", "qc", "director_rewrite", "change_review")}
def round_cost(n, sec, easy_share, img_regen, vid_regen, upgrade_rate=None, api=False,  # api=False: claude_cli (ĐÃ CHỐT) end_frame_share=0.0, final_regen=0):
    easy = round(n * easy_share); hard = n - easy
    images = n * (1 + end_frame_share) * (1 + img_regen)
    up1 = sd("1080p", sec, sec) if upgrade_rate is None else cost.seedance_tokens("1080p", "9:16", sec, sec) / 1000 * upgrade_rate
    video = easy * sd("720p", sec) * (1 + vid_regen) + hard * sd("480p", sec) * (1 + vid_regen) + hard * up1 * (1 + final_regen)
    claude = (llm["director"] + llm["director_byd"] + llm["motion"] + images * llm["qc"] + n * (1 + vid_regen) * llm["qc"]
              + (img_regen + vid_regen) * n * llm["director_rewrite"] + 0.5 * n * llm["change_review"]) if api else 0
    return images * img + video + claude
# B thấp round_cost(5,5,.5,0,0) · B giữa round_cost(8,5,.5,1,1,end_frame_share=.25) · B cao round_cost(8,8,0,3,2,.0070,end_frame_share=.5,final_regen=1)
# C thấp round_cost(20,5,.5,0,0) · C giữa round_cost(30,5,.5,1,1,end_frame_share=.25) · C cao round_cost(40,8,0,3,2,.0070,end_frame_share=.5,final_regen=1)
```
